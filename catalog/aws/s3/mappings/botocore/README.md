# Generated botocore-owned S3 mapping

[`runtimeconditions.sdk-mapping.yaml`](runtimeconditions.sdk-mapping.yaml) is generated static metadata for the S3 surface owned by botocore 1.43.70.

It binds 116 botocore client methods to the 112 canonical operations in the selected AWS S3 extension release, including four declared compatibility aliases. It also contains eight paginator bindings, four waiter bindings, and the 119 canonical Condition templates supplied by the language-neutral service mapping.

This mapping is the owner-qualified operation target for boto3 resource bindings and s3transfer execution paths. botocore owns it because botocore owns the public low-level client model and versions that behavior independently of boto3.

The operation semantics come from AWS's authoritative Smithy model and the reviewed Service Operations Semantic Bridge. [`../../model/botocore-sdk-annotations.yaml`](../../model/botocore-sdk-annotations.yaml) contains only botocore-specific compatibility aliases. Maintainers review those compact inputs and generated summaries, not this YAML line by line.
